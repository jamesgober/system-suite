# system-suite v0.9.4 - Plain warnings

**Two messages from WASP's gateway on Windows.** No API change.

## What is system-suite?

<strong>system-suite</strong> is the foundation for Rust services: one dependency that brings system facts and a process guard, application paths, environment variables, configuration, logging, metrics, audit records, a registry, signal handling, time, ids, randomness, and secret storage, plus a kernel that starts them in order, supervises background work, reports health and readiness, captures crashes, and shuts everything down in reverse.

## Changed

- **A lock the application turned off is not a warning.** `Builder::single_instance(false)` is a choice made in code, so it is now one info line, "the single-instance lock is off", with `set_by` "the application". The lock turned off by the configuration (`guard.lock = false`, from the file or the environment) is still a warning, which now says another copy can start against the same files and what to do.

## Fixed

- **FAT and exFAT drives are named in the error.** On Windows an application directory on a drive without access control lists was refused with the advice to fix its permissions or delete it, neither of which helps there. The error now names the drive type and says to move the directories to an NTFS drive, or to use a portable install, which accepts such a drive. A file refused there gets the same plain message.
- **Files accepted on such a drive are reported.** A configuration, `.env`, or `file:` secret file on a FAT or exFAT drive is still accepted, but the boot now logs a warning naming it and saying to move it to an NTFS drive; a reload does the same for a secret file.
