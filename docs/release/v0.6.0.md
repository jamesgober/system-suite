# system-suite v0.6.0 - Optimisation

**Measured: every target met.** v0.6.0 adds a boot benchmark harness, publishes the numbers, and keeps them from slipping with a regression gate. A booted system starts in well under a millisecond, stops in about 0.2 ms, holds under 100 KiB of heap, and when idle uses no CPU and wakes no thread.

## What is system-suite?

<strong>system-suite</strong> is the foundation for Rust services: one dependency that brings system facts and a process guard, application paths, environment variables, configuration, logging, metrics, audit records, a registry, signal handling, time, ids, randomness, and secret storage, plus a kernel that starts them in order, supervises background work, reports health and readiness, captures crashes, and shuts everything down in reverse.

## What's in 0.6.0

| Measure | Target | Linux | Windows |
|---|---|---|---|
| boot to ready | under 5 ms | 0.078 ms | 0.31 ms |
| stop to exit | under 50 ms | 0.16 ms | 0.20 ms |
| idle CPU and wake-ups, 5 s | 0 | 0 and 0 | measured from sys-lib 0.4 |
| urgent-line check | about 1 ns | 0.20 ns | 0.19 ns |
| heap held by a booted system | under 256 KiB | 98 KiB | 99 KiB |

(Medians on an AMD Ryzen 9 9950X3D; the method is in `docs/PERFORMANCE.md`.)

- **`cargo bench --bench boot`:** the harness, standard library only.
- **A regression gate:** against stored baselines, over 105% and over a noise floor, so a real slowdown fails and run-to-run noise does not.
- **`System::boot_timeline()`:** how long each boot step took.
