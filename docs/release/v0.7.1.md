# system-suite v0.7.1 - Memory watermark

**A service can now shed load before it runs out of memory.** v0.7.1 adds the urgent line's memory watermark, which was waiting on sys-lib 0.4.

## What is system-suite?

<strong>system-suite</strong> is the foundation for Rust services: one dependency that brings system facts and a process guard, application paths, environment variables, configuration, logging, metrics, audit records, a registry, signal handling, time, ids, randomness, and secret storage, plus a kernel that starts them in order, supervises background work, reports health and readiness, captures crashes, and shuts everything down in reverse.

## What's in 0.7.1

- **The memory watermark:** set `[kernel] memory_watch` and the kernel raises the urgent line to `Shed` when the OS reports memory pressure or the share of memory used reaches `[kernel] memory_shed` (90% by default; inside a container, of the container's limit). It clears after three calm readings.
- **Off by default:** each reading wakes a thread, and an idle system otherwise wakes nothing. One reading is about 10 us on Linux and 2 us on Windows.
- **It never overrides anyone:** the line moves only from `Normal` to `Shed` and back, by compare-and-swap, so a `Lockdown` is never lowered, a stop is never undone, and a `Shed` someone else set stays theirs.
- **Idle CPU on Windows and macOS** is now measured, through sys-lib 0.4, and the benchmark runs on all three OSes in CI.
